# Working Together Review 🤝

## 프로젝트 개요
팀간/팀원 평가 시스템 - 직원들이 다른 팀과 팀원들을 평가하고 관리자가 결과를 확인할 수 있는 웹 애플리케이션입니다.

## 🎯 주요 기능

### ✅ 현재 완료된 기능

#### 1. 인증 및 권한 관리
- ✅ 로그인/로그아웃 기능
- ✅ 첫 로그인 시 비밀번호 설정
- ✅ 역할 기반 권한 관리 (관리자, 팀장, 팀원)
- ✅ 세션 관리 (sessionStorage 사용)

#### 2. 대시보드
- ✅ 사용자별 맞춤 대시보드
- ✅ 평가 진행 현황 표시
- ✅ 차트를 통한 시각화 (Chart.js)

#### 3. 팀간 평가
- ✅ 다른 팀 평가하기 (관리자 제외)
- ✅ 5가지 평가 항목 (협업 태도, 업무 전문성, 커뮤니케이션, 문제 해결 능력, 전반적 만족도)
- ✅ 평가 진행률 표시
- ✅ **분기별 평가 선택** (1~4분기) ⭐ NEW!
- ✅ **평가 수정 불가 기능** - 한번 평가하면 수정 불가
- ✅ **모든 평가 완료 시 자동 로그아웃** 🎉 NEW!

#### 4. 팀원 평가
- ✅ 팀장/관리자만 접근 가능
- ✅ 자기 팀 팀원 평가
- ✅ 4가지 평가 항목 (업무 성과, 협업 능력, 자기개발, 종합 평가)
- ✅ 상세 코멘트 작성 가능
- ✅ **분기별 평가 선택** (1~4분기) ⭐ NEW!
- ✅ **평가 수정 불가 기능** - 한번 평가하면 수정 불가
- ✅ **모든 평가 완료 시 자동 로그아웃** 🎉 NEW!

#### 5. 평가 결과 (관리자 전용)
- ✅ 분기별 팀 순위 확인
- ✅ 팀별 상세 평가 결과
- ✅ 팀원별 평가 결과
- ✅ 기간별 필터링 (년도/분기 선택)

#### 6. 직원 관리 (관리자 전용)
- ✅ 직원 추가/수정/삭제
- ✅ 역할 변경
- ✅ 비밀번호 재설정
- ✅ 팀 배정

#### 7. 팀 관리 (관리자 전용)
- ✅ 팀 추가/수정/삭제
- ✅ 팀 색상 설정
- ✅ 팀별 인원 관리

#### 8. 설정
- ✅ 시스템 제목 변경
- ✅ 비밀번호 변경
- ✅ 평가 기간 선택

## 🚀 기술 스택
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Data Storage**: LocalStorage (브라우저 기반)
- **Charts**: Chart.js 4.4.0
- **Icons**: Font Awesome 6.4.0
- **Architecture**: Multi-page SPA (Single Page Application)

## 📁 프로젝트 구조

## 📊 데이터 구조

### LocalStorage Keys
- `evaluation_teams`: 팀 데이터
- `evaluation_employees`: 직원 데이터
- `evaluation_team_eval`: 팀간 평가 데이터
- `evaluation_member_eval`: 팀원 평가 데이터
- `evaluation_passwords`: 비밀번호 (Base64 인코딩)
- `evaluation_system_title`: 시스템 제목
- `evaluation_selected_date`: 선택된 평가 기간 (년도, 분기)

### 분기 시스템
- **1분기**: 1~3월
- **2분기**: 4~6월
- **3분기**: 7~9월
- **4분기**: 10~12월

  - 결과 조회도 분기 단위로 변경

- ✅ **로그인 페이지 중복 표시 문제 해결**

## ⚠️ 주의사항
- 모든 데이터는 브라우저의 LocalStorage에 저장됩니다
- 브라우저 캐시를 지우면 모든 데이터가 삭제됩니다
- 중요한 데이터는 정기적으로 백업하세요
- **평가는 한번 제출하면 수정할 수 없으니 신중하게 작성해주세요**
- **모든 평가를 완료하면 자동으로 로그아웃됩니다**

## 💡 사용 팁
1. **분기별 평가 관리**: 1~4분기를 선택하여 분기별로 평가를 관리하세요
2. **평가 완료 확인**: 평가가 완료되면 "평가 완료" 배지가 표시되며 더 이상 수정할 수 없습니다
3. **자동 로그아웃**: 모든 평가를 완료하면 자동으로 로그아웃 안내가 나타납니다
4. **진행률 확인**: 대시보드에서 전체 평가 진행률을 한눈에 확인하세요
5. **팀별 비교**: 관리자는 평가 결과 페이지에서 팀별 순위와 상세 점수를 확인할 수 있습니다
